## How to Use the Labs

1. Select a lab from the collection.
2. Read its instructions and identify the objective.
3. Work exclusively against the authorized lab environment.
4. Perform reconnaissance systematically.
5. Record discovered paths, services, banners, application details, and other findings.
6. Document why each discovery is relevant.
7. Review the underlying defensive security concept after completing the challenge.

Skills represented across this collection include:

- Web reconnaissance
- Directory enumeration
- Gobuster
- Burp Suite
- Pluck CMS security
- Source-code analysis
- Banner grabbing
- Port scanning
- Port knocking
- SSH reconnaissance
- Network enumeration
- CTF methodology
